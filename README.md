# Instituto Raiz Viva

Projeto da Experiência Prática I (Desenvolvimento Front-end): site institucional de uma ONG fictícia com HTML5 semântico, formulário com validações nativas e máscaras de CPF, telefone e CEP.

## Estrutura
- `index.html`: página inicial
- `pages/projetos.html`: projetos sociais e como participar
- `pages/cadastro.html`: cadastro de doadores e voluntários
- `css/style.css`: estilos
- `js/formulario.js`: máscaras e validações complementares
- `img/`: logotipo e ilustração em SVG, PNG e WebP
